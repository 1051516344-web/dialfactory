# DialFactory System · 项目目标

## 系统定位

钟表表盘工厂**生产数据管理系统**。

不是 ERP。不是 MES。是专注于「订单生产轨迹」和「质量数据」的轻量系统。

## 核心目标

1. **记录**：每张订单从制一到总QC的完整生产轨迹
2. **透明**：任何时候知道订单在哪道工序、停了多久
3. **追溯**：返工原因、不良品来源、质量事件可回溯
4. **分析**：积累数据后自动统计瓶颈工序、异常趋势、返工率

## 使用场景

| 场景 | 说明 |
|---|---|
| 跟单员日常 | 车间推进订单、记录异常 |
| 部门交接 | 制一→制二→制三→制四的质量门禁 |
| 外协追踪 | 12家供应商的发出/返回/验收 |
| 管理分析 | 跨订单统计损耗、返工、周期 |

## 设计原则

1. **真实优先**：只记录真实发生的事，不许虚构数据
2. **简单操作**：操作必须比现有流程快
3. **可离线**：工厂网络不稳定
4. **可扩展**：从制二起步，逐步覆盖全工厂
5. **数据安全**：不暴露敏感信息
