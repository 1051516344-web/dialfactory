# DialFactory System · 开发规范

## 技术栈

| 层 | 选择 | 约束 |
|---|---|---|
| 前端 | 纯 HTML/CSS/JS | 不引入 React/Vue |
| 后端 | Supabase（BaaS） | 不自建服务器 |
| 数据库 | PostgreSQL（Supabase 托管） | |
| 部署 | GitHub Pages | |
| 离线 | Service Worker + IndexedDB | |

## 编码规范

| 规则 | 示例 |
|---|---|
| 函数命名：`verbNoun()` | `renderFlow()` `saveOrder()` |
| 组件统一暴露 `render(data, container)` | |
| 事件处理用 `addEventListener`，不用 `onclick` 字符串 | |
| 数据流单向：`api.js → state → render` | |
| 错误必须处理，不能吞掉 | `try/catch` + toast |
| 中文注释优先 | |

## 禁止

- 禁止全局变量（除 `app.state`）
- 禁止一个函数超过 80 行
- 禁止在 HTML 里写 `onclick="..."` 字符串
- 禁止重复渲染——先比较数据是否变化
- 禁止嵌套 JSON 数组在数据库里

## 与旧 DialFlow 的关系

- 不继承旧代码
- 不引用旧文件名
- 不兼容旧数据格式
- 只保留已验证的业务规则
