# DialFactory System · 系统边界

## 覆盖

```
制一 ─── 制二 ─── 制三 ─── 制四 ─── 总QC
  │        │        │        │
  └────────┴────────┴────────┴── 12家外协
```

| 模块 | 说明 |
|---|---|
| 订单管理 | 创建、查询、交期、状态总览 |
| 工序追踪 | 推进节点、记录状态、时间 |
| 异常记录 | 类型/数量/严重度/处理方式 |
| 返工追踪 | 次数、原因、返工路线 |
| 部门移交 | 质量门禁、数量确认、责任交接 |
| 外协管理 | 供应商、发出/返回/验收 |
| 统计分析 | 耗时、不良率、返工率、趋势 |

## 不覆盖

| 不覆盖 | 原因 |
|---|---|
| 库存管理 | ERP 范畴 |
| 人员排班/绩效 | HR 范畴 |
| 设备管理 | IoT 范畴 |
| 财务核算 | ERP 范畴 |
| 客户关系管理 | CRM 范畴 |
| 自动排产 | 当前阶段不需要 |
| 手机原生 App | PWA 已满足离线需求 |
