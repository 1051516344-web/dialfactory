# DialFactory · 数据录入模板

> 用途：在开始任何软件设计前，用 Excel 录入真实生产数据，验证业务模型
> 目标数据量：5 条工艺路线、10 张历史订单、覆盖所有部门
> 约束：不涉及数据库、不涉及代码、纯业务数据

---

## 使用说明

1. 将以下每个表格复制到 Excel 的一个 Sheet 中
2. 按照「示例行」的格式，填入工厂真实数据
3. 标注为「假设」的列 = 当前不确定，请根据工厂实际填写或标注为 N/A
4. 标注为「必填」的列 = 不填则整行数据无法使用
5. 填完后，数据将用于验证 Business Model V1 是否与真实业务匹配

---

## Sheet 1：部门清单

**说明：** 列出工厂所有的生产部门。这是最基础的主数据。

| 部门名称 | 顺序号 | 部门类型 | 备注 |
|---------|--------|---------|------|
| 制一 | 1 | 生产 | |
| 制二 | 2 | 生产 | |
| 制三 | 3 | 生产 | |
| 制四 | 4 | 生产 | |
| 总QC | 5 | 检验 | |

**填写指引：**
- **部门名称**（必填）：工厂实际的部门名称。如果和示例不同，按实际填
- **顺序号**（必填）：部门在工厂流程中的先后顺序。1→2→3→4→QC
- **部门类型**（必填）：生产 或 检验。检验部门执行记录标记"完成"时必须填产出数量
- **备注**：部门的补充说明，可空

## Sheet 2：客户清单

**说明：** 列出工厂所有活跃客户。用于订单创建时的客户选择。

| 客户全称 | 客户简称 | 是否活跃 |
|---------|---------|---------|
| （示例）深圳时诺钟表有限公司 | 时诺 | 是 |
| | | 是 |
| | | 是 |

**填写指引：**
- **客户全称**（必填）：公司完整名称
- **客户简称**（必填）：工厂日常口语中的简称，2-4 个字
- **是否活跃**（必填）：是/否。已停止合作的客户填"否"（保留记录但不用于新订单）

**目标数量：** 至少 10 家（17 家更好）

## Sheet 3：工序清单

**说明：** 列出工厂所有可执行的工序。这是工厂的"能力目录"。

| 工序编号 | 工序名称 | 工序类型 | 默认执行部门 | 是否必经 | 备注 |
|---------|---------|---------|------------|---------|------|
| （示例）P01 | 冲压成型 | 加工 | 制一 | 是 | |
| （示例）P02 | CD纹加工 | 加工 | 制二 | 否 | |
| （示例）P03 | 太阳纹加工 | 加工 | 制二 | 否 | |
| （示例）P04 | 喷砂 | 加工 | 制二 | 否 | |
| （示例）P05 | 银白电镀 | 加工 | 制三 | 否 | |
| （示例）P06 | 金色电镀 | 加工 | 制三 | 否 | |
| （示例）P07 | 移印 | 加工 | 制四 | 否 | |
| （示例）P08 | 装字钉 | 加工 | 制四 | 否 | |
| （示例）P09 | 总QC检验 | 检验 | 总QC | 是 | |
| | | | | | |
| | | | | | |

**填写指引：**
- **工序编号**（必填）：P01-P99 格式。按实际编号体系填写
- **工序名称**（必填）：工厂对这道工序的实际称呼
- **工序类型**（必填）：加工 / 检验 / 辅助。检验 = 有质量判定职责，做完了必须报产出数量
- **默认执行部门**（必填）：这道工序通常在哪个部门执行
- **是否必经**（假设）：所有路线都必须包含的工序填"是"。如果不确定，先空着
- **备注**：补充说明，可空

**目标数量：** 至少 15 道工序（覆盖所有部门）

**关键问题（需工厂确认）：**
- 电镀是否按颜色区分工序（银白电镀 vs 金色电镀），还是同一道电镀工序选参数？
- 底质纹理（CD纹/太阳纹）是独立工序还是同一工序的不同参数？

## Sheet 5：历史订单

**说明：** 录入最近完成的 10 张真实订单。不需要精确数据，但需要反映真实业务。

| 订单编号 | 客户简称 | 订单数量 | 交期 | 底质纹理 | 电镀颜色 | 喷砂类型 | 路线名称 | 实际完成日期 | 备注 |
|---------|---------|---------|------|---------|---------|---------|---------|------------|------|
| （示例）SN-2026-0088 | 时诺 | 500 | 2026-08-20 | 太阳纹 | 银白60s | 轻砂 | 太阳纹+银白标准路线 | 2026-08-18 | |
| | | | | | | | | | |
| | | | | | | | | | |

**填写指引：**
- **订单编号**（必填）：工厂实际使用的编号格式。如果格式有规律（如"客户代号-年份-序号"），按实际格式填
- **客户简称**（必填）：与 Sheet 2 对应
- **订单数量**（必填）：客户要多少件
- **交期**（必填）：客户要求的交货日期
- **底质纹理**（必填）：无底纹 / 太阳纹 / CD纹
- **电镀颜色**（必填）：如"银白60s""金色""玫瑰金"
- **喷砂类型**（必填）：-（无喷砂）/ 重砂 / 轻砂 / 中砂
- **路线名称**（必填）：与 Sheet 4 对应
- **实际完成日期**（选填）：如果记得就填，用于对比交期
- **备注**（选填）：任何值得记录的信息

**目标数量：** 10 张

**关键问题（需工厂确认）：**
- 底质纹理、电镀颜色、喷砂类型——这三个字段的选项是否完整？是否有遗漏的类型？
- 订单编号是否工厂自己编的，还是客户给的单号？

## Sheet 6：工序执行记录

**说明：** 选 2-3 张已完成的订单，记录它们走过的完整工序路径。这是验证业务模型最关键的步骤。

| 订单编号 | 顺序号 | 工序名称 | 执行部门 | 状态 | 返工次数 | 产出数量 | 开始日期（约） | 完成日期（约） | 备注 |
|---------|--------|---------|---------|------|---------|---------|-------------|-------------|------|
| （示例）SN-2026-0088 | 1 | 冲压成型 | 制一 | 已完成 | 0 | | 8月1日 | 8月2日 | |
| （示例）SN-2026-0088 | 2 | 太阳纹加工 | 制二 | 已完成 | 0 | | 8月3日 | 8月5日 | |
| （示例）SN-2026-0088 | 3 | 喷砂 | 制二 | 已完成 | 0 | | 8月5日 | 8月6日 | |
| （示例）SN-2026-0088 | 4 | 银白电镀 | 制三 | 已完成 | 1 | | 8月7日 | 8月10日 | 第一批色差，返工一次 |
| （示例）SN-2026-0088 | 4 | 银白电镀 | 制三 | 已完成 | 1 | | 8月11日 | 8月13日 | 返工批次 |
| （示例）SN-2026-0088 | 5 | 移印 | 制四 | 已完成 | 0 | | 8月14日 | 8月15日 | |
| （示例）SN-2026-0088 | 6 | 总QC检验 | 总QC | 已完成 | 0 | 470 | 8月16日 | 8月17日 | 合格470，报废30 |
| | | | | | | | | | |
| | | | | | | | | | |

**填写指引：**
- **订单编号**（必填）：与 Sheet 5 对应
- **顺序号**（必填）：在订单中的执行顺序。注意——返工的工序保留同顺序号，用返工次数区分
- **工序名称**（必填）：实际执行的工序名称
- **执行部门**（必填）：实际在哪个部门做的
- **状态**（必填）：已完成 / 进行中 / 暂停 / 等待中
- **返工次数**（必填）：0=正常，1=第一次返工，2=第二次返工。正常和返工是两条记录
- **产出数量**（条件）：QC 类型工序必填。其他工序能记就记，不记得空着
- **开始/完成日期**（选填）：大概日期即可（精确到天）
- **备注**（选填）：记录返工原因、异常情况

**目标数量：** 2-3 张完整走完的订单，每张 5-8 条执行记录

**关键问题（需工厂确认）：**
- 返工时，是重做同一工序（电镀→返工电镀），还是会跳回更早的工序（移印发现电镀问题→退回制三）？
- 每道工序的产出数量，实际中能否获取？还是仅 QC 节点能获取？

## Sheet 7：质量事件

**说明：** 记录生产过程中真实发生的质量问题。

| 订单编号 | 发生在哪道工序 | 缺陷类型 | 影响数量 | 处理方式 | 简要描述 |
|---------|-------------|---------|---------|---------|---------|
| （示例）SN-2026-0088 | 总QC检验 | 色差 | 30 | 报废 | 银白色偏黄，与客户签样不一致 |
| （示例）SN-2026-0088 | 银白电镀 | 电镀不良 | 50 | 返回电镀 | 镀层不均匀，局部发雾 |
| | | | | | |
| | | | | | |

**填写指引：**
- **订单编号**（必填）：与 Sheet 5 对应
- **发生在哪道工序**（必填）：在哪个工序的执行过程中发现的
- **缺陷类型**（必填）：从以下类型中选：色差 / 电镀不良 / 划伤 / 沙眼 / 变形 / 其他
- **影响数量**（必填）：多少件有这个问题
- **处理方式**（必填）：返回电镀 / 返回磨板 / 重做 / 特采 / 报废
- **简要描述**（选填）：一句话描述问题

**目标数量：** 至少 5 条

**关键问题（需工厂确认）：**
- 缺陷类型列表是否完整？还有没有常见类型遗漏？
- 处理方式列表是否完整？

## 数据汇总

| Sheet | 目标数量 | 对验证业务模型的意义 |
|-------|---------|-------------------|
| 1. 部门清单 | 5 行 | 确认组织架构 |
| 2. 客户清单 | ≥10 行 | 确认客户规模 |
| 3. 工序清单 | ≥15 行 | 确认工厂能力范围 |
| 4. 工艺路线 | 3-5 条 | 确认标准流程 |
| 5. 历史订单 | 10 张 | 确认订单数据完整性 |
| 6. 工序执行记录 | 2-3 张订单的完整路径 | **最关键**——验证工序推进逻辑 |
| 7. 质量事件 | ≥5 条 | 确认异常类型和处理方式 |
| 8. 外协供应商 | 3-5 家 | 为 V1.5 做准备 |
