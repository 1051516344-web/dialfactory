# DialFactory System · 数据录入规则

## 录入优先级

| 优先级 | 字段 | 原因 |
|---|---|---|
| 🔴 必填 | 订单号、客户、路线 | 没有这些订单无法追踪 |
| 🟡 有则填 | 开始/结束时间、投入/产出数量 | 车间做不到每次都填，但不填不影响流程 |
| 🟢 选填 | 备注 | 辅助信息 |

## 时间录入

- 精度：**日期级**。不要求小时和分钟
- 系统自动记录的是「操作时间」（什么时候点的按钮），不是「实际发生时间」
- 允许用户手动修正时间
- 不填时间不影响状态流转

## 数量录入

- 粗胚数量：订单创建时填一次
- 投入/产出：每道工序可选填
- QC 节点：产出数量必填（这是统计基础）

## 异常录入

- 在哪发现就记录在哪道工序
- 类型从预设列表选，不够时选「其他」+ 备注
- 数量必填（不良品统计的基础）
- 严重度和处理方式可选

## 禁止录入

| 禁止 | 原因 |
|---|---|
| 编造时间 | 宁可空着 |
| 编造数量 | 污染统计 |
| 事前填写 | 发生再记 |
| 跳过异常 | 不良品数据是核心资产 |

## 数据成熟度标签

每个数据字段标注成熟度，继承自工厂知识库：

| 标签 | 含义 | 录入行为 |
|---|---|---|
| L1 | 已确认，强制 | 必填或默认值 |
| L2 | 经验规则 | 可选，提示推荐值 |
| L3 | 待收集 | 隐藏，不收数据 |

## 录入设备

- 平板浏览器（触摸优化）
- 按钮尺寸 ≥ 44px
- 尽量减少文字输入，多用选择/确认
